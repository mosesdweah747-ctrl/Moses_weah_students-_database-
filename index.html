Getting started

Set up students first. Then record attendance and assessment marks. Choose a term and class to calculate results and prepare individual report cards. This version is configured with Grades 7–12 as a starting point; you can also type another class name.

Important: This is an offline starter database. Data stays in this browser on this device. It is not a secure multi-user school server. Keep student information private and download backups regularly.

Privacy: this starter version has no online account, password protection, or automatic cloud backup. Use it on a device you control. Avoid entering unnecessary sensitive family information.

School and user setup

Every school, teacher or administrator can personalize this application. These details are saved only in this browser on this device.

The app is open-source and can be reused by different schools and educators under the MIT License. Each installation/browser keeps its own records. For shared multi-user access, a secure online database and user accounts must be added.
